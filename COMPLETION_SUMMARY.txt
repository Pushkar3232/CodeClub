🚀 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════

1. USER SENDS MESSAGE
   └─ Types message in input field and clicks send

2. MESSAGE SAVED
   └─ Sent to Firestore: chats/{communityId}/messages/{messageId}

3. ALL NOTIFIED
   └─ All community members' devices receive update via Stream

4. UI UPDATES
   └─ Message appears in everyone's chat with sender info

5. RESULT
   └─ ✅ Everyone sees the message instantly!
